# validation-language-mockup

Python mockup for a validation language.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Usage

```bash
python -m validation_language_mockup
```

## Tests

```bash
pytest
```

## Lint

```bash
ruff check .
ruff format .
```
